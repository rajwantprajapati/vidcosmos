# Logo

The Vidcosmos logo, drawn with the theme's tokens so it follows light and dark mode: teal disc (`brand`), coral orbit (`highlight`), play symbol in `on-brand`, wordmark in `ink`.

- `variant="full"` in top bars and footers (minimum 96 px wide); `variant="mark"` for avatars, loading screens and small spaces (minimum 20 px).
- Keep clear space equal to the disc's height around it.
- For files (social images, favicons, documents) use the SVGs in the Logos asset group.
