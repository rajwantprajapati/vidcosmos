# Card

A surface that groups related content: a settings section, a usage summary, a step in a flow. Cards have a hairline border and no shadow; they lift with `shadow-sm` only when `interactive` and hovered.

- Default padding `md` (`space-6`); `sm` for dense grids and phones.
- `selected` marks the chosen card in a set (an angle, a plan) with `brand-soft`.
- Don't nest cards inside cards.
