# Badge

One or two words of status or metadata beside a title. Never interactive.

- Tones map to meaning: `success` Ready / Published, `brand` Generating / In progress, `warning` Scheduled / Edited / Expiring, `danger` Failed / Missed, `neutral` Draft and counts, `info` tips.
- `highlight` (coral) is for brand moments only, such as "New" on a marketing page, never for status.
- The word carries the meaning; colour supports it. Add an `icon` when the badge stands far from its subject.
