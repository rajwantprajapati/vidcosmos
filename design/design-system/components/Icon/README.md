# Icon

The handful of Lucide-style outline glyphs the components use, at 1.75 px stroke, coloured by `currentColor`. For anything else, use `lucide-react` directly with `strokeWidth={1.75}` at 16, 20 or 24 px.

- Decorative by default (`aria-hidden`); pass `label` only when the icon stands alone and carries meaning.
- Names: `play`, `check`, `clock`, `alert`, `x`, `sparkles`, `arrow-right`, `arrow-up`, `mic`, `pencil`, `loader`, `film`, `send`.
- No emoji, no filled icons.
