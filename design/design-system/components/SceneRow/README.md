# SceneRow

One scene in the editor's scene list: number, thumbnail, title, template and duration. Clicking selects the scene for preview and scene-scoped chat.

- The selected scene uses `brand-soft` and `aria-current`.
- `edited` marks scenes the user changed by hand (a whole-video rewrite asks before replacing them); `failed` marks scenes whose narration failed and need a retry.
- Durations in seconds with one decimal ("9.8 s").
