# SegmentedControl

Two to five mutually exclusive options that apply immediately: format, length, language, light or dark. The selected option is a raised pill on the sunken track.

- Give the group an accessible `label` ("Format").
- Use `lang: 'hi'` on an option whose label is in Devanagari.
- More than five options, or options that need explaining: use a select or radio cards instead.
