# ProgressBar

Determinate progress for jobs: generation, narration, rendering, uploading. Pair it with a label that says what is happening now.

- Label in plain words with counts: "Recording narration (4 of 7 scenes)", "Rendering 1080p".
- Progress only moves forward. When a step's length is unknown, keep the bar where it is and update the label.
- The value is always shown as text, so the bar never carries meaning alone.
